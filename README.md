# YJ Open Tools

Tools I build for my own work and share with anyone who wants them, mostly extensions and skills that get more out of Claude.

Each tool lives in its own repo so you can star, fork and install just the one you need. This page is the index.

## Tools

| Tool | What it does | Get it |
|---|---|---|
| **API Looper** | Bring your own API key (Kimi, OpenAI, OpenRouter, DeepSeek, Gemini, Anthropic) into Claude Desktop. Claude plans; your model does the bulk work on your credits. | [youssefjalloul-inova/api-looper](https://github.com/youssefjalloul-inova/api-looper) |
| **Skill Router** | Keep your Claude skills in a library and load only the one each task needs, so fewer tokens go to idle skills. | [yj-skill-library/skill-router](https://github.com/yj-skill-library/skill-router) |
